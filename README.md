# NBA Fantasy 王朝｜二十季重建聯盟

免費、免註冊、打開瀏覽器即可遊玩的籃球總經理模擬遊戲。建立一支原創擴張隊，透過擴編選秀、自由球員簽約、球員培養與季後賽戰術，挑戰二十季王朝。

## 遊戲玩法

- **建立球隊**：自訂經理名稱與球隊名稱，從虛構球員候選池挑選陣容，並留意薪資上限。
- **經營陣容**：簽下自由球員、釋出球員，管理球員合約、年齡、評分與薪資。
- **挑戰季後賽**：模擬例行賽、查看聯盟排名，為每輪季後賽選擇戰術。
- **打造王朝**：球員會成長或老化；每季有新秀加入，最多經營二十季。
- **收藏成就**：首次奪冠、累積冠軍與歷史級戰績會解鎖獎章。

## 帳號、排行榜與存檔

本作是純前端 GitHub Pages 遊戲，**沒有伺服器帳號或密碼登入**。經理名稱只是儲存在此瀏覽器的本機個人檔案，排行榜也只顯示此瀏覽器上的本機紀錄，並非跨玩家的全球排行榜。遊戲存檔、個人紀錄與獎章使用瀏覽器 `localStorage` 保存；清除瀏覽器資料或更換裝置可能使資料消失。請使用遊戲內的匯出存檔功能備份，並妥善保管匯出的檔案。

本站不需外部服務、不投放廣告，也不會將遊戲存檔傳送至伺服器。無法使用 `localStorage` 的瀏覽器或隱私模式可能無法保留進度。

## 開始遊玩

直接用瀏覽器開啟 `index.html`，或在 GitHub Pages 啟用此 repo 的 `main` 分支、根目錄作為發布來源後，透過 Pages 提供的網址遊玩。這是靜態 HTML/CSS/JavaScript 專案，不需要建置流程或伺服器端程式。
