# 台北 Fantasy｜二十季籃球王朝

一款免註冊、直接在瀏覽器遊玩的籃球總經理模擬遊戲。接掌台北 Fantasy，在薪資上限下打造陣容、簽約自由球員、進行球員交易、挑選新秀，並用二十個球季建立自己的王朝。

## 遊戲功能

- **豪華總管儀表板**：查看戰績、薪資與稅線、老闆心情、先發／替補戰力、賽季階段和球隊核心球員卡。
- **完整名單管理**：調整先發與替補、查看年齡、總評、潛力、薪資與合約年限。
- **球員交易**：選擇市場球員，提供球員作為交易籌碼；交易結果會記錄在交易歷史與賽季日誌。
- **自由球員市場**：在薪資預算及 15 人名單限制內補強陣容。
- **新秀選秀**：模擬每季選秀、查看新秀潛力，並將新秀加入球隊。
- **賽季與球員發展**：推進賽季階段、模擬戰績及季後賽；休賽季會更新合約、球員年齡與能力。
- **生涯、排行榜與成就**：查看球隊紀錄；排行榜和成就保存在本機，不會與其他玩家同步。
- **存檔備份**：自動存入瀏覽器 `localStorage`，並支援 JSON 匯出／匯入。

## 開始遊玩

此專案是純 HTML、CSS、JavaScript 靜態網站，無需安裝套件或建置。可直接開啟 `index.html`。部署 GitHub Pages：到 repository 的 **Settings → Pages**，選擇 **Deploy from a branch**、`main` 分支和 `/(root)` 資料夾後儲存。

## 存檔、登入與排行榜

遊戲沒有伺服器帳號或密碼登入；經理名稱是此瀏覽器的本機個人設定。存檔、成就、交易紀錄和排行榜使用 `localStorage`，不會上傳；清除瀏覽器資料或更換裝置可能使資料消失。請定期匯出 JSON 備份。本機排行榜只統計目前瀏覽器的紀錄，並非全球排行榜。
