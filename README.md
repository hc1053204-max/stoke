# TPBL 籃球經理｜穩定核心版

免安裝、免註冊的瀏覽器籃球經理遊戲。接掌一支球隊，管理球員名單及薪資，模擬例行賽並爭奪季後賽冠軍。存檔只儲存在目前瀏覽器的 `localStorage`。

## 遊戲功能

- 總管中心：戰績、聯盟排名、勝率、球隊戰力、薪資和先發陣容。
- 球員名單：設定先發、檢視評價與潛力、釋出球員。
- 自由球員與交易：本土/洋將簽約、薪資上限檢查、一對一球員交易。
- 賽季進度：七隊各 36 場、聯盟共 126 場，逐場模擬並記錄賽果。
- 排名與季後賽：例行賽結束後，前六名進入附加賽、四強與總冠軍賽。
- 年度獎項：例行賽結束後公布 MVP、得分王、最佳教練與年度第一隊，並保留歷屆 MVP。
- 存檔：自動儲存，並支援 JSON 匯出與匯入。

## 分層結構

遊戲維持純 HTML/CSS/JavaScript，依責任拆分，不需套件或建置工具：

- `index.html`：頁面骨架與腳本載入順序。
- `styles.css`：版面、響應式樣式與動效。
- `js/data.js`：資料模型、存檔、名單及共用查詢。
- `js/trades.js`：簽約、釋出、交易及薪資/名單規則。
- `js/schedule.js`：例行賽程與賽事模擬。
- `js/playoffs.js`：季後賽輪次、冠軍與新賽季。
- `js/awards.js`、`js/awards-ui.js`：年度獎項計算與顯示。
- `js/ui.js`：主要頁面渲染、使用者操作及匯入/匯出。

## 開始遊玩

建議透過 GitHub Pages 網址遊玩，或使用本機靜態伺服器預覽。所有檔案需保持原有相對路徑。GitHub Pages 可在 repository 的 **Settings → Pages** 設定部署來源。

## 存檔與資料相容

遊戲沒有伺服器登入；存檔不會上傳。清除瀏覽器資料會移除本機存檔，請定期匯出備份。載入既有 `front-office-tpbl-optimized-v1` 存檔時會正規化資料，盡量保留球員、戰績與已完成賽事。年度獎項新增於同一份本機存檔中，既有存檔可繼續使用。
